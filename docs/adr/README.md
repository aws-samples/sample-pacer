# Architecture Decision Records

Format: context → decision → consequences. Status: all **Accepted** unless noted.

## The figures in these records are not benchmarks

Many of these records carry throughput numbers, and several turn on them. They are
**development-phase experiment records**, held to a different standard than anything in
[`docs/benchmarks/`](../benchmarks/README.md):

- They were taken to **decide something**, against the tree as it stood that day, with
  harnesses often built for one question and then abandoned.
- Those harnesses are **not published**. Every driver is welded to one cluster's nodepools,
  AZ-pinned buckets and session claims, so a reader cannot re-run an arm — and should not
  assume one would reproduce.
- They are not controlled against the real alternative, not repeated enough to support a
  spread, and are frequently **superseded or retracted inside the same document**. That last
  one is deliberate: a wrong number that changed a decision is part of that decision's
  history, so it is corrected in place rather than quietly deleted.

**So do not quote a figure from an ADR.** The numbers meant for quoting — stated baseline,
one variable, interleaved repetitions, raw client report and the script alongside — live in
[`docs/benchmarks/`](../benchmarks/README.md), under the contract written there.
